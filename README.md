# Неотложка+

Электронная клиническая методичка по неотложной медицине для врачей Республики Казахстан.

## Current state
This repository is being initialized from the existing Неотложка+ working build and project specification. The current standalone HTML build is preserved as `index.html`.

## Clinical safety
This is a working project, not an officially approved national clinical handbook. Clinical content must be checked against current Kazakhstan Ministry of Health protocols and authoritative guidelines. Draft or unreviewed material must never be presented as verified. Do not invent doses, thresholds, treatment pathways, or escalation criteria.

## Main scope
- PAT, ABCDE, Pediatric BLS and PALS
- Pediatric respiratory emergencies: severe pneumonia, croup, bronchiolitis, epiglottitis, acute asthma exacerbation, foreign-body aspiration, and central hypoventilation
- Expansion to adult and pediatric emergencies across all organ systems
- Russian/Kazakh language support, mobile-first interface, search, favorites, references and medical review status
